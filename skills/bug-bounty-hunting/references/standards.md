# Standards and References — Bug Bounty Hunting

Real standards, frameworks, and platform documentation for the procedures in `SKILL.md`. Nothing here is a placeholder.

## Vulnerability scoring and classification

- FIRST — Common Vulnerability Scoring System v4.0 specification and calculator: https://www.first.org/cvss/
- CWE — Common Weakness Enumeration (vulnerability classes referenced in reports): https://cwe.mitre.org/
- OWASP Top 10 (2021) — the vulnerability-class map used in the targeting menu: https://owasp.org/www-project-top-ten/

## Platforms and program rules

- HackerOne — HackerOne Platform documentation, program pages, Hacktivity (disclosed reports): https://docs.hackerone.com/
- Bugcrowd — Bugcrowd platform documentation and program briefs: https://docs.bugcrowd.com/
- Intigriti — Intigriti platform documentation: https://help.intigriti.com/
- YesWeHack — YesWeHack program documentation: https://docs.yeswehack.com/

## Disclosure

- ISO/IEC 29147:2018 — Vulnerability disclosure
- ISO/IEC 30111:2019 — Vulnerability handling processes
